# لوحة الإدارة من we-pal (نسخة مرجعية)

نسخة من مصدر لوحة الإدارة في مستودع المؤسسة `sdfpro1/we-pal`، نُقلت إلى هنا بإذن من المؤسسة لنعمل على نسخة منها.

- **مصدرها:** نسخة المستودع المرفوعة بتاريخ 17 نوفمبر 2026 (`frontend/src`)، وقد يكون المستودع المنشور أحدث منها.
- **ما فيها:** صفحات اللوحة (`src/pages/admin`)، ومكوّناتها (`src/components/Admin`، `src/components/AdminEditor`)،
  وكل ما تستورده من واجهات الـ API والأدوات والمكوّنات المشتركة، وأنماطها، وملف المسارات `src/routes.js`،
  وقواعد التجربة `docs/ADMIN-UX.md`.
- **ليست جزءًا من البناء:** المجلد مستثنى من TypeScript وESLint، ولا يدخل في بناء الموقع. هي مرجع ننقل منه صفحة صفحة
  إلى `app/admin` بإطار الموقع الحالي (vinext) وبهوية ويبال الجديدة.

## الفرق التقني

| | we-pal | wepal (هنا) |
|---|---|---|
| الإطار | React Router 7 + Vite | vinext (توافق Next app router) على Cloudflare Workers |
| اللغة | JSX | TSX |
| الأنماط | Tailwind 4 + ملفات azraq | CSS بتوكنات `app/identity.css` |
| البيانات | Laravel API | بيانات تجريبية الآن، ثم الـ API نفسه عبر `NEXT_PUBLIC_WEPAL_API` |
