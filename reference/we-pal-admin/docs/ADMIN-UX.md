# قواعد تجربة الاستخدام في لوحة الإدارة (ومنطقة الأعضاء)

قاعدة ثابتة طلبها أمجد (17 نوفمبر 2026): «المفترض نسهّل مش نصعّب». كل صفحة جديدة أو معدَّلة في اللوحة تتبعها،
وأي مراجعة للواجهة تفحصها.

## 1. الصف أو البطاقة كلها تفتح العنصر

في كل جدول أو قائمة أو مجموعة بطاقات، الهدف الأساسي للنقر هو **الصف كله**، لا أيقونة القلم الصغيرة في «إجراءات».
النقر في أي مكان من الصف يفتح العنصر (صفحة التحرير أو التفاصيل، أو نافذته إن لم تكن له صفحة).

استعمل المكوّن المشترك، لا معالجات نقر خاصة بكل صفحة:

```jsx
import { ClickableRow, RowLink, RowButton } from '../../components/common/ClickableRow';

<ClickableRow key={item.id}>                    {/* <tr> افتراضيًا؛ as="li" أو "div" أو "article" للبطاقات */}
  <td><RowLink to={`/admin/editor/news/${item.id}`}>{title}</RowLink></td>
  …
  <td><button type="button" className="wp-icon-act" aria-label={`حذف: ${title}`} onClick={…}><Trash2 aria-hidden="true" /></button></td>
</ClickableRow>
```

- **العنوان رابط حقيقي** (`RowLink`)، فيعمل Ctrl/Cmd+نقر والنقر الأوسط (تبويب جديد) على العنوان وعلى الصف.
  إن كان العنصر يُفتح في نافذة حوار لا صفحة فالعنوان `RowButton`.
- **الإجراءات الثانوية** (حذف، إخفاء، اعتماد، المزيد…) تبقى أزرارًا، وتعمل وحدها: الصف يتجاهل النقر على أي زر أو رابط
  أو حقل داخله، فلا تفتح العنصر معها. لمنطقة غير تفاعلية لا يجب أن تفتح العنصر: `data-row-ignore`.
- **لوحة المفاتيح وقارئ الشاشة**: التبويب يصل إلى العنوان، وEnter يفتحه، وحلقة التركيز ترسم حول الصف كله.
  القلم المكرّر للعنوان (إن بقي) خارج ترتيب التبويب: `tabIndex={-1} aria-hidden="true"`.
- **الإشارة البصرية**: مؤشر اليد، وخلفية خفيفة عند المرور، والعنوان يُسطَّر (أصناف `wp-row` و`wp-row-link`
  في `styles/components.css`). لا تُضِف `hover:bg-…` خاصًّا.
- تحديد نص في الصف (لنسخه) لا يفتح العنصر.
- صف لا يُفتح (عنصر بذرة عرض مقفل مثلًا) يبقى `<tr>` عاديًّا بلا `RowLink`.

## 2. البطاقات والأرقام التي تشير إلى مكان تذهب إليه فعلًا

بطاقة ملخّص أو رقم («بلا نسخة إنجليزية 53»، «بانتظار المراجعة 4»…) يبدو قابلًا للنقر يجب أن يفتح القائمة
**مرشَّحة بما يعنيه الرقم**. لذلك:

- مرشّحات صفحة القائمة (الحالة، النوع، التبويب…) في عنوان الصفحة (`useSearchParams`)، لا في `useState` وحده،
  فالرابط `?status=draft` أو `?missing=en` يغيّر ما يظهر.
- الخادم يرسل `to` لكل بطاقة يطابق مرشّحًا تقرؤه الصفحة. بطاقة لا مرشّح لها تبقى نصًّا لا رابطًا.
- عناصر الرسوم (حسب النوع، حسب الحالة…) روابط إلى القائمة مرشَّحة بذلك العنصر حين تدعمه الصفحة.

## 3. أزرار الأيقونات

- زر الأيقونة وحدها هدفه 36×36px على الأقل (44px باللمس): الصنف `wp-icon-act`. لا `p-1` / `p-1.5` حول أيقونة 14px.
- له `aria-label` يذكر الفعل والعنصر («حذف: عنوان المصدر»)، و`title` للتلميح.
- الفعل الأساسي لا يكون أيقونة وحدها: هو الصف أو زر بنص.

## الفحص

عند مراجعة أي صفحة في اللوحة: جرّب النقر على الصف خارج العنوان، وCtrl+نقر، والتبويب ثم Enter، والنقر على كل بطاقة
رقم، وقِس أزرار الأيقونات. صفحة تكسر قاعدة هنا تُصلح قبل الدمج.
